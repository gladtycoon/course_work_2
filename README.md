# ✈️ SkyTracker — мониторинг воздушного пространства

> Курсовая работа по объектно-ориентированному программированию  
> **Тема:** Сбор и отображение данных о самолетах в воздушном пространстве выбранных стран

---

## 📌 О проекте

**SkyTracker** — это консольное приложение, которое позволяет:

- Выбрать страну (или несколько стран) для мониторинга
- Получить географические границы (`boundingbox`) страны через геокодер **Nominatim** (OpenStreetMap)
- Запросить текущие данные о самолетах через API **OpenSky Network**
- Отобразить список воздушных судов в выбранном регионе

Проект демонстрирует принципы ООП: инкапсуляцию, наследование, полиморфизм и работу с внешними API.

---


## 🌍 Используемые API

### 1. Nominatim (OSM)
- **URL:** `https://nominatim.openstreetmap.org/search`
- **Цель:** получить `boundingbox` страны (юг, север, запад, восток)
- **Пример:** `q=Canada&format=json&limit=1`

> Пример ответа (фрагмент):  
> `"boundingbox": ["41.676", "83.336", "-141.002", "-52.619"]`

### 2. OpenSky Network
- **URL:** `https://opensky-network.org/api/states/all`
- **Цель:** получить список самолетов в регионе
- **Параметры:** `lamin`, `lomin`, `lamax`, `lomax` (координаты boundingbox)

> Формат ответа — массив `states` с данными о каждом самолете:  
> `[icao24, callsign, origin_country, longitude, latitude, ...]`
